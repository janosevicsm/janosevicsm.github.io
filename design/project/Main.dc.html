Spec sheet
for a person.

Direction - “Industrial editorial.” Huge, wide display type set against hairline rules and small machine-plate labels (No. / Model / Year). A nod to eMachy’s industrial world without a single gear icon.

Light paper alternates with deep ink sections. One accent, used sparingly: dots, fills, one highlighted word.
