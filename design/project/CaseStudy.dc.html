01 - The problem

Machineschange handsslowly.

Buying a used press or a machining centre usually means digging through scattered dealer sites, in several languages, then chasing sellers by phone.

eMachy puts new and used industrial machines in one place, in six languages: buyers contact sellers directly, and sellers get leads in a built-in inbox instead of paying commission.

02 - My role

From thefirst commit.

As co-founder and tech lead I owned the technical side end to end - and the way the team works.

  1. 01

    Every repository

    Created and structured all of the product’s repositories and the cross-repo workflow that ties them together.

  2. 02

    Architecture calls

    .NET 8 with Clean Architecture, PostgreSQL, an Angular 20 front end - chosen and set up for a small team to move fast.

  3. 03

    Infrastructure as code

    Azure, provisioned with OpenTofu, so environments are reproducible rather than hand-built.

  4. 04

    How the team builds

    Set up Claude Code as an agentic software factory - shared automation, code review and release workflows.
